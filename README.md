# PP Study

เว็บติวสอบแบบหน้าเดียว ใช้ได้ทั้งมือถือและคอม และใช้แบบออฟไลน์ได้หลังเปิดครั้งแรก

- **ข้อสอบ**: ข้อสอบสนามใหญ่ปี 2562 (ข้อเท็จจริงเล่าใหม่ให้กระชับ) จับเวลา เขียนคำตอบ ดูเฉลยแบบเช็กลิสต์ทีละประเด็น และเพิ่มข้อสอบของตัวเองได้
- **ฎีกา**: บทเรียนจากฎีกาที่ธงคำตอบอ้าง พร้อมรอบทบทวน
- **ตัวบท**: ตัวบทวิชาหลักและวิชาเลือก ค้นคำ และกระโดดไปมาตราที่ต้องการ
- **เป้าหมาย**: วันสอบเป้าหมาย เวลาเรียนต่อสัปดาห์ บันทึกเวลา และความสำเร็จที่ปลดล็อก
- **บอร์ด**: บอร์ดแยกตามรอบการเรียน

ข้อมูลส่วนตัว (คำตอบ เป้าหมาย บอร์ด) เก็บในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่ได้ส่งขึ้นเว็บ

ที่มา: ตัวบทจากระบบฐานข้อมูลกฎหมายของสำนักงานคณะกรรมการกฤษฎีกา (ณ 26 พ.ย. 2569) และราชกิจจานุเบกษา · ข้อสอบและธงคำตอบต้นฉบับ: สำนักงานคณะกรรมการตุลาการศาลยุติธรรม
