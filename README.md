# PP Study

หน้านี้เป็นทางเข้าแอป PP Study ซึ่งย้ายไปทำงานใน Claude เพื่อให้ AI ตรวจคำตอบได้ในตัว

- `index.html` หน้าทางเข้า และปุ่มส่งออกข้อมูลจากเว็บเดิม (ถ้ามีในเบราว์เซอร์)
- `sw.js` ล้างแคชของแอปเดิมแล้วถอนตัวเอง
- `data/` ตัวบทกฎหมาย (ข้อความจากเว็บสำนักงานคณะกรรมการกฤษฎีกา) และข้อสอบที่เรียบเรียงย่อ

ตัวบทกฎหมายและคำพิพากษาไม่มีลิขสิทธิ์ตาม พ.ร.บ.ลิขสิทธิ์ พ.ศ. 2537 มาตรา 7
